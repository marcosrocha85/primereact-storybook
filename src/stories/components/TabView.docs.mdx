## Basic Usage

Three tabs, each with its own body content. Clicking a header activates that panel; only one panel is visible at a time.

        commodo consequat. Duis aute irure dolor in reprehenderit in voluptate
        velit esse cillum dolore eu fugiat nulla pariatur.
      </p>
    </TabPanel>

        odit aut fugit, sed quia consequuntur magni dolores eos qui ratione

## Icons in Headers

Use `leftIcon` or `rightIcon` on `TabPanel` to pair each tab with a PrimeIcons class. The icon appears alongside the header label and helps users scan tabs at a glance.

## Disabled Tab

Set `disabled` on a `TabPanel` to prevent the user from navigating to it. Use this when a section is temporarily unavailable — for example, content that requires a completed previous step.

<div style={{ width: "680px" }}>
  <TabView>
    <TabPanel header="Overview">
      <p className="m-0">
        Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod
        tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim
        veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea
        commodo consequat.
      </p>
    </TabPanel>
    <TabPanel header="Specifications">
      <p className="m-0">
        Sed ut perspiciatis unde omnis iste natus error sit voluptatem
        accusantium doloremque laudantium, totam rem aperiam, eaque ipsa quae ab
        illo inventore veritatis.
      </p>
    </TabPanel>
    <TabPanel header="Reviews (unavailable)" disabled>
      <p className="m-0">
        This content is not reachable while the tab is disabled.
      </p>
    </TabPanel>
  </TabView>
</div>

## Scrollable Headers

Add `scrollable` to `TabView` when the number of tabs may exceed the available horizontal space. Navigation arrows appear so the user can scroll through the header list without wrapping.

<div style={{ width: "480px" }}>
  <TabView scrollable>
    {[
      "Overview",
      "Specifications",
      "Reviews",
      "Shipping",
      "Returns",
      "Support",
      "Legal",
    ].map((tab) => (
      <TabPanel key={tab} header={tab}>
        <p className="m-0">
          Content for the <strong>{tab}</strong> tab — Lorem ipsum dolor sit
          amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut
          labore et dolore magna aliqua.
        </p>
      </TabPanel>
    ))}
  </TabView>
</div>

  {/* more tabs… */}
</TabView>`}
